# 오닐 CAN SLIM 검색기

윌리엄 오닐의 CAN SLIM 조건으로 평일 장 마감 무렵 국내 전 종목(코스피·코스닥, ETF·스팩·우선주 제외)을 검색해 폰 앱 화면에 보여 줍니다. 종가매매 검색기(`jongga`)와 같은 구조입니다.

- **앱 주소:** https://kyuiklee.github.io/oneil/
- 폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 처음 한 번 설정
1. Settings → Pages → Source를 **GitHub Actions**로
2. Settings → Secrets and variables → Actions → `DART_API_KEY` 등록 (OpenDART 인증키). 없으면 실적 조건(C·A) 없이 가격·거래량 조건만 적용됩니다.
3. (선택) Settings → Secrets and variables → Actions → `CUSTOMS_API_KEY` 등록. 공공데이터포털(data.go.kr)에서 **관세청_품목별 수출입실적** 활용신청 후 받은 일반 인증키(Decoding 키 권장, Encoding 키도 됨). 없으면 품목 수출 조건 없이 실행되고 앱에서 그 줄이 숨겨집니다.
4. Actions → **오닐 CAN SLIM 검색** → Run workflow (첫 실행은 실적 수집 때문에 10~20분 걸릴 수 있습니다)

## 조건
| 글자 | 내용 | 적용 |
|---|---|---|
| C | 최근 분기 순이익 전년 동기 대비 증가율 (DART, 공시 다음 날부터) | 앱에서 끔·흑자↑·20·25·50% |
| A | 연간 순이익 3년 연평균 증가율, ROE | 앱에서 끔·플러스·15·25% |
| N | 52주 고가 15% 이내 + 35일 베이스(깊이 8~35%) 피벗을 처음 돌파, 피벗 위 5% 이내 | 엔진 |
| S | 돌파일 거래량 50일 평균의 1.4배 이상 | 엔진 |
| L | RS 점수(3·6·9·12개월 수익률 가중, 전 종목 순위 1~99) 70 이상 | 앱에서 70·80·85·90 |
| I | 매집 지표: 50일 상승일 거래량 ÷ 하락일 거래량 (기관 수급 대신 가격·거래량으로 근사) | 점수 |
| M | 지수가 50일선 위·50일선 상승이면 상승 추세, 200일선 아래면 하락 추세 | 앱에서 무시·하락장 쉼·상승장만 |

### 추가 조건 (몇 배 상승주의 공통점)
| 조건 | 내용 | 적용 |
|---|---|---|
| 영업이익 가속 | 최근 분기 영업이익 전년 대비 +30% 이상이고, 직전 분기의 전년 대비 증가율보다 높음 (DART). '가속+마진↑'은 분기 영업이익률도 전년 같은 분기보다 오른 경우 | 앱에서 끔·가속·가속+마진↑ |
| 품목 수출 | 관세청 품목(HS코드)별 수출의 최근 3개월 합계 전년 대비 증가율. 월간 확정치 공표를 감안해 다음 달 16일부터 반영 | 앱에서 끔·플러스·20·50% |

품목 수출은 `engine/export_map.json`에 적은 종목에만 붙습니다 (어떤 회사가 어떤 품목을 수출하는지는 자동으로 알 수 없음). 화장품·라면·변압기·반도체 장비·2차전지·선박·방산·의료기기 등으로 시작했으니, 종목코드를 더하거나 HS코드를 새로 넣어 쓰세요. 조건을 켜면 매핑에 없는 종목은 빠집니다. 상세 화면 태그에 `영업익가속`, `마진개선`, `수출+NN%`(↑는 한 달 전보다 빨라짐)가 붙습니다. 점수 계산은 바꾸지 않았습니다.

추세 조건: 종가 > 50일선 > 200일선, 200일선 상승 중, 20일 평균 거래대금 20억 이상, 주가 2,000원 이상.

유형은 두 가지입니다.
- **베이스 돌파**: 위 N·S 조건으로 피벗을 처음 넘은 날
- **50일선 눌림**: 최근 60일 안에 돌파가 있었고 RS 80 이상인 종목이 거래량 줄며 50일선(±2%)에서 지지받은 날 (오닐의 추가 매수 자리)

매도는 앱 백테스트에서 고릅니다: 손절 -5/-7/-8/-10%, 익절 +15/+20/+25/+30%, 최대 보유 5~60거래일. 기본값은 오닐 원칙대로 손절 -7%, 익절 +20%, 40거래일(8주).

## 구성
- `engine/config.json` — 엔진 조건 값
- `engine/screen.py` — CAN SLIM 지표·점수
- `engine/fund.py` — OpenDART 분기·연간 실적 (공시일 기준 시계열, 순이익·매출·영업이익)
- `engine/export.py`, `engine/export_map.json` — 관세청 품목별 월간 수출과 종목 매핑
- `engine/data.py` — 시세 수집 (네이버 차트 → FinanceDataReader → pykrx)
- `engine/build.py` — 오늘 후보 + 과거 후보의 매수 후 60일 경로 계산
- `site/` — 앱 화면

## 한계
- EPS 대신 순이익 증가율을 씁니다. 유상증자 등으로 주식 수가 크게 늘면 실제 EPS 증가율보다 높게 나옵니다.
- 기관 보유(I)는 거래소 수급 대신 가격·거래량 기반 근사치입니다.
- 현재 상장 종목만 대상이라 상장폐지 종목이 빠져 있고, 백테스트가 실제보다 좋게 나올 수 있습니다.

검색 결과는 조건 필터링이며 매수 권유가 아닙니다.
